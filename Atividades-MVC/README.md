# Atividades ASP.NET Core MVC

Projetos separados da Atividade Prática 04.

Cada pasta contém um projeto ASP.NET Core MVC independente.

## Exercícios
01 - Escola
02 - Academia
03 - Cinema
04 - Restaurante
05 - Hotel
06 - Cadastro de Alunos
07 - Catálogo de Produtos
08 - Biblioteca
09 - Clínica Veterinária
10 - Loja de Eletrônicos
11 - Sistema de Notas
12 - Sistema de Estoque
13 - Sistema de Pedidos
14 - Sistema de Cursos
15 - Sistema de Cadastro de Funcionários

## Como executar
Abra a pasta do exercício no Visual Studio, restaure as dependências e execute o projeto.

Os exercícios utilizam dados em memória e não utilizam banco de dados, conforme o enunciado.
